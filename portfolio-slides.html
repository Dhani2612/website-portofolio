DHT22 Relay LCD | IoT Monitoring

ArduinoC++IoTHardware

Proyek IoT ini saya buat sebagai implementasi untuk membantu UMKM pengrajin furnitur lokal. Kelembapan udara yang tidak stabil dapat merusak material kayu sensitif, sehingga dibutuhkan sistem pengawasan otomatis.


Dilengkapi sensor DHT22 untuk mengukur suhu dan kelembapan ruangan secara real-time yang ditayangkan ke layar LCD I2C 20x4. Saat program C++ Arduino mendeteksi nilai menembus batas aman, modul Relay akan otomatis mengaktifkan penstabil udara secara mandiri.

Fitur Utama

• Pembaca suhu dan kelembapan ruangan tanpa sela
• Dasbor fisik LCD I2C
• Relay otomatis dari ambang toleransi mikrokontroler

github.com/Dhani2612/temp-humidity-monitor

Kripto Sakti | Secure LMS

PythonFlaskCryptographyMySQL

Purwarupa LMS yang mendemonstrasikan integrasi algoritma keamanan siber dan kriptografi modern ke dalam alur kerja pendidikan digital. Saat mahasiswa mengunggah file tugas, sistem mengenkripsinya menggunakan kombinasi AES-256 dengan Caesar Cipher sehingga dokumen asli tidak pernah disimpan utuh di server.


Untuk verifikasi transkrip, sistem menyisipkan watermark digital menggunakan teknik Steganografi LSB. Password dilindungi dengan hashing scrypt, dan endpoint vital dilindungi Rate Limiting untuk mencegah serangan brute-force.

Fitur Utama

• Hybrid Cryptography (AES-256 + Caesar)   • Steganografi LSB untuk watermark
• Autentikasi scrypt   • Rate Limiting   • HTTPS development

github.com/Dhani2612/LMS-kripto-projek

PupukKu | Integrated Distribution Web App

Next.jsTypeScriptPrismaSupabaseTailwind

Platform web full-stack untuk mendigitalisasi dan mengelola rantai pasok distribusi pupuk komersial. Dibangun dengan Next.js (App Router) dan TypeScript untuk performa tinggi dan type-safety end-to-end.


Memisahkan logika bisnis ke dalam dua portal: Dasbor Administrator untuk manajemen operasional dan Dasbor Customer untuk pelacakan alokasi. Backend mengimplementasikan Prisma ORM dengan Supabase (PostgreSQL), dan UI dirancang dengan Tailwind CSS serta shadcn/ui.

Fitur Utama

• Portal multi-peran (Admin & Customer)   • Next.js App Router & Server Components
• Prisma ORM + Supabase   • CRUD terpusat   • Pelacakan kuota individu
